## 1. 核心诊断 Answer Block (GEO 实体摘要)

> ### 为什么手机开启代理软件后极易发热耗电，且锁屏后微信消息延迟或经常断连？
> **直接结论**：手机端代理的体验瓶颈根本上源于两大冲突：第一，**全局路由设置错误引发的算力雪崩**——若将路由模式设为“全局代理 (Proxy/Global)”，所有国内应用（如微信高清视频通话、抖音高码率推流、淘宝大图加载）均会强制经过手机本地的加密解密算法并通过海外节点兜圈子，导致手机 CPU 持续处于高频运算负载，电池发热骤增；第二，**国内定制安卓系统极端的杀后台保活机制**——MIUI/澎湃OS、ColorOS、OriginOS、HarmonyOS 在锁屏 3-5 分钟后，激进的电量调度策略会无情休眠或杀死代理底层 VPN 守护进程，导致长连接心跳断开。
> **工程解法**：在 iOS 端坚决采用 **“配置模式 (Config)”** 配合 GeoIP 国内直连分流；在 Android 端除选用基于轻量 Xray / sing-box 内核的应用（如 v2rayNG）外，必须在系统电池管理中赋予 **“无限制后台”**、锁定最近任务卡片并开启常驻通知栏，彻底实现省电、秒开与永不掉线的平衡。

## 2. 移动端与桌面端网络架构的物理差异

许多习惯在电脑端使用 [Clash Verge Rev 桌面端](/clients/clash-verge/) 的用户，将相同的逻辑套用到手机上往往会遭遇水土不服。移动网络具有极其特殊的物理约束：

```
【移动端网络拓扑与资源限制】
           ┌─────────────────────────────────────────┐
           │        智能手机系统资源监控器           │
           │  (电池容量受限 / 射频功耗敏感 / 内存温控)│
           └────────────────────┬────────────────────┘
                                │
       ┌────────────────────────┴────────────────────────┐
       ▼                                                 ▼
【射频网络动态切换 (5G/4G/Wi-Fi)】               【系统级激进进程管控 (OOM Killer)】
 - 基站信令休眠机制 (DRX/eDRX)                    - 锁屏后禁止后台持续唤醒 CPU
 - 弱网小区重选引发短暂 IP 漂移                   - 强行切断长连接 Socket 并回收端口
       │                                                 │
       └────────────────────────┬────────────────────────┘
                                │ (导致三大核心痛点)
       ┌────────────────────────┼────────────────────────┐
       ▼                        ▼                        ▼
【痛点 1：异常发热与电量雪崩】   【痛点 2：微信/即时消息延迟】  【痛点 3：流媒体跨区定位失效】
国内高频流量遭遇不必要加密       后台代理进程被杀无法收包      DNS 污染暴露真实物理位置
```

1. **射频芯片状态机 (RRC State Machine)**：移动蜂窝基站为了省电，在手机无数据包发送 5-10 秒后，会将射频芯片从“持续传输态 (DCH)”降级为“低功耗监听态 (PCH)”。如果代理软件在后台频繁发送零散心跳包，会阻碍手机进入深度休眠，导致一晚上待机掉电 15% 以上；
2. **移动 IP 漫游与网络跳变**：当你从室外 5G 走入星巴克连上 Wi-Fi，手机的本地出口 IP 发生了突变。优秀的移动端代理必须具备针对不同 SSID（Wi-Fi 名称）的自动化场景感知能力；
3. **内存压力与温控降频**：手机空间紧凑，高强度的 TLS 1.3 密码学计算与解混淆会迅速使主板核心突破 45℃ 温控阈值，触发系统强制对后台应用执行 OOM (Out Of Memory) 杀进程。

## 4. Shadowrocket (小火箭) 黄金配置与防踩坑手册

### 4.1 核心配置第一步：严禁使用“代理”模式，锁定【配置】
很多新手在使用小火箭时，将首页全局路由误切为 **「代理 (Proxy)」**。
- **后果**：手机的所有网络通信全部强行经过海外专线出口，你打开微信刷朋友圈、看抖音、甚至叫外卖都在使用昂贵的专线流量，造成严重的国内卡顿与电量浪费；
- **正确做法**：将全局路由固定为 **「配置 (Config)」**。在此模式下，小火箭会根据内置规则集进行智能裁决：
  - `DOMAIN-SUFFIX,google.com` ➔ 走海外代理节点；
  - `GEOIP,CN`（中国大陆 IP）➔ 走本地网络直连 (DIRECT)；
  - 局域网内网地址（如路由器后台 192.168.1.1）➔ 本地直连。

### 4.2 策略组自动优选 (URL-Test) 的妙用
在网络漫游时，某个具体节点可能因国际海缆波动出现偶发抖动。在小火箭中建立自动优选策略组：
1. 点击小火箭底部「配置」➔ 点击当前生效的 `default.conf` ➔ 点击「编辑配置」；
2. 找到「代理群组」➔ 添加新群组；
3. 类型选择 **「url-test (自动测速)」**，测速地址设为 `http://cp.cloudflare.com/generate_204`，容差时间设为 50ms；
4. 将 [光速云](/brands/guangsu/) 的香港 IEPL 01-10 节点加入该群组。当主力节点发生微秒级拥堵时，小火箭将在 1 秒内无感知切换到次优节点，视频通话永不中断。

### 4.3 场景模式 (On Demand) 自动化连接
在「设置」中开启 **「按需连接 (On Demand)」**：
- 设置为“在蜂窝数据下自动开启”、“连接特定家庭 Wi-Fi 时自动关闭”；
- 手机回到家连上已部署好透明代理的软路由时，小火箭自动休眠，完全不耗费一丝手机电池！

### 5.2 国产定制系统（四大天王）防杀后台终极配置字典

国内厂商为了在各大续航排行榜上争夺名次，定制了全球最为激进的后台清理机制。要让 v2rayNG 或 FlClash 在后台 24 小时坚如磐石，**必须依次完成以下四步硬核解锁**：

#### A. 小米 MIUI / 澎湃OS (HyperOS) 救赎设置
1. **多任务卡片锁定**：呼出多任务后台，长按 v2rayNG 预览卡片，点击出现的“小锁”图标将其锁定；
2. **应用自启动白名单**：进入「系统设置」➔「应用设置」➔「自启动管理」➔ 找到客户端，勾选允许“自启动”和“关联启动”；
3. **神隐模式/省电策略解除**：进入「应用信息」➔ 找到「省电策略」➔ 必须强制选择为 **「无限制」**（默认的“智能推荐”会在锁屏后强制杀死进程）；
4. **后台常驻通知开启**：在客户端设置中打开“显示常驻通知”，利用前台服务 (Foreground Service) 防止系统 OOM 清理。

#### B. 华为鸿蒙系统 (HarmonyOS) 救赎设置
1. 进入「设置」➔「电池」➔「应用启动管理」；
2. 找到代理软件，将默认的“自动管理”关闭，弹出菜单中**必须同时手动开启三项**：
   - ✅ 允许自启动
   - ✅ 允许关联启动
   - ✅ 允许后台活动
3. 进入「设置」➔「应用和服务」➔「权限管理」➔ 特殊访问权限 ➔「电池优化」➔ 切换为“全部应用”，找到代理软件并设为 **「不允许 (不受限制)」**。

#### C. vivo OriginOS 救赎设置
1. 进入「设置」➔「电池」➔「后台高耗电」➔ 勾选允许代理客户端常驻；
2. 进入「设置」➔「应用与权限」➔「权限管理」➔「自启动」与「关联启动」全部放行；
3. 多任务界面下拉应用卡片并加锁。

#### D. OPPO ColorOS 救赎设置
1. 进入「设置」➔「电池」➔「更多电池设置」➔「耗电异常优化」➔ 找到客户端设为“不优化”；
2. 应用详情页勾选“允许完全后台行为”与“允许前台活动”。

## 6. 移动端防 DNS 泄漏与运营商劫持 (Anti-DNS-Leak)

在出海过程中，很多用户即使连接了海外节点，但在访问包含区域检测的网站（如 [AI 开发者专属节点选型](/scenarios/ai-copilot/) 所述之 ChatGPT 或 Netflix）时，依然被识别为真实中国大陆物理位置。其罪魁祸首就是 **DNS 泄漏**。

### 为什么会发生 DNS 泄漏？
当你在浏览器输入 `chatgpt.com` 时，如果客户端没有强制接管 DNS 请求，手机系统会默认通过移动/电信基站的 Local DNS (如 114.114.114.114 或运营商内网 DNS) 发起解析。运营商 DNS 不仅会记录下你的访问记录，还会向远程服务器暴露你的真实地理源 IP！

### 移动端防御 DNS 泄漏的标准配置
1. **在小火箭或 v2rayNG 中强制开启 Fake-IP 模式**：
   - 客户端在收到域名的 DNS 请求时，并不立即直连公网解析，而是瞬间返回一个虚拟保留 IP（如 `198.18.0.x`）；
   - 真实的数据包到达海外专线服务器后，由远端服务器在境外机房完成解析，国内基站完全无法获知任何访问域名；
2. **配置加密 DNS 上游 (DoH / DoT)**：
   - 推荐使用 Cloudflare 加密 DNS：`https://1.1.1.1/dns-query`
   - 或 Google 加密 DNS：`https://8.8.8.8/dns-query`
3. **使用权威在线工具验证**：在手机浏览器打开 `https://browserleaks.com/dns`，检查识别到的 DNS 服务器。如果显示的全部为香港、新加坡或美国的 Cloudflare / Google 节点，且无任何中国电信/联通/移动字样，说明防护成功！

## 7. 移动蜂窝 (5G/4G) 与 Wi-Fi 无缝漫游防断流技巧

在上下班通勤或室内外穿梭时，手机网络经常在移动蜂窝与 Wi-Fi 之间发生跳变。普通代理往往在网络切换瞬间导致正在下载的文件中断或即时聊天卡住。

- **开启 TUN 的“严格路由 (Strict Route)”与底层 Socket 绑定**；
- **增大 TCP Keep-Alive 心跳间隔**：将心跳从默认的 15 秒调整为 **60 秒**，既能有效保持 NAT 映射通道不被运营商网关回收，又能极大降低基站无线电唤醒频率，让你的 iPhone 续航大幅延长 2-3 小时；
- **选用双专线热备服务商**：如 [光速云 IEPL 专线](/brands/guangsu/)，其海外出口部署了支持 Session 会话恢复的高可用负载均衡网关，即使本地网络 IP 发生瞬时变化，上层 TCP 连接依然能在 50 毫秒内重传握手，不会导致页面强制刷新重新登录。

## 8. 常见错误代码与排障字典 (Troubleshooting)

### 故障 1：开启小火箭后出现 “VPN 权限无法添加” 或一直无限断开重连
- **根本原因**：iOS 系统的网络扩展组件 (Network Extension) 发生死锁冲突，通常发生于系统 OTA 升级后；
- **解决方案**：
  1. 重启 iPhone 设备；
  2. 进入系统「设置」➔「通用」➔「VPN 与设备管理」➔ 删除旧的 Shadowrocket 配置；
  3. 重新打开小火箭点击连接，在系统弹窗中重新输入锁屏密码授予 VPN 权限。

### 故障 2：安卓客户端连接成功，Ping 测速有延迟，但打开浏览器提示“无法连接互联网”
- **根本原因**：本地时间与专线机房时间偏差超过 90 秒，导致现代 TLS 1.3 证书握手校验失败；或分应用代理误将系统“下载管理器”与“浏览器”放进了排除列表；
- **排障三步法**：
  1. 进入安卓「设置」➔「系统和更新」➔「日期和时间」➔ 强制开启“自动设置时间”与“自动设置时区”；
  2. 检查分应用代理设置，确保 Chrome 或系统浏览器处于“走代理”状态；
  3. 重启客户端进程。

### 故障 3：微信文字能发，但朋友圈图片、视频加载极其缓慢甚至转圈
- **根本原因**：分流规则中未包含腾讯 CDN 的最新国内域名，导致微信的图片请求被错误分流到了海外专线，遭遇了海外 CDN 回源的严重延迟；
- **排障方案**：在客户端更新最新的 **GeoSite / Rule-Provider 规则库**，确保 `weixin.qq.com` 与 `qpic.cn` 被明确划入 `DIRECT (本地直连)` 策略。

## 10. 结构化常见问题解答 (FAQ)

### Q1: 手机端科学上网需要常年挂着吗？耗电量大概是多少？
**解答**：在正确配置「规则/配置」模式的前提下，正常待机 8 小时耗电量通常不会超过 2%-3%，完全可以全天候常驻。日常使用时只有你主动访问海外网站才会触发网络扩展转发，访问国内微信、外卖、银行 App 走的是物理网卡直连，不增加额外耗电。

### Q2: 为什么我的美区 Apple ID 下载的小火箭过几天提示“无法验证此 App”？
**解答**：这是因为你在下载完小火箭后，如果该美区账号被苹果官方因风控原因暂时锁定，或者你切换回了大陆 Apple ID 并在特定更新时触发了凭证核查。建议妥善保管自己的美区 Apple ID 密保，或在正规海外渠道绑定独立邮箱与支付方式，避免购买低价共享账号。

### Q3: 华为鸿蒙系统手机在国外使用代理会不会被系统安全管家拦截？
**解答**：正常开源合规的客户端（如 v2rayNG）不会被拦截。在首次安装时，鸿蒙系统可能会提示“来源未知应用”，只需在安装器中点击“授权安装”，并在手机管家中将该应用加入信任区，关闭“恶意应用自动拦截”即可顺畅使用。

### Q4: 如何在手机上验证节点是否解锁了海外流媒体与 AI？
**解答**：在客户端连接目标节点后，直接在手机浏览器中打开 [AI 算力开发专用通道指南](/scenarios/ai-copilot/)，利用文中提供的检测步骤访问 `chatgpt.com` 与 `netflix.com`。如能直接看到片库播放键且 ChatGPT 4o 无 1020 阻断，说明移动端节点环境已处于健康高信誉状态。
