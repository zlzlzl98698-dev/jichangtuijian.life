## 🌟 项目简介 (Overview)

**机场life (`jichangtuijian.life`)** 是一座面向出海科研、跨境外贸团队、AI 开发者与技术极客的**独立跨境网络可观测性评测中心**。

当前跨境代理服务市场充斥着信息不对称：劣质公网直连冒充内网专线、虚假跑分掩盖单线程丢包、跑路资金盘频频暴雷。本项目通过多区域分布式探针、7x24 小时晚高峰自动化压测与反作弊审计，向公众提供**具备真实可重复验证性、数据源透明、架构中立**的选型知识库。

- 🌐 **官方正式域名**：[https://jichangtuijian.life/](https://jichangtuijian.life/)
- 📊 **数据更新周期**：季度性全网回测与周度网络抖动健康度巡检
- ⚖️ **中立承诺**：所有评测样本严格标注 `实测数据 (Measured)` 与 `官方宣称 (Vendor Data)`，商业推广链接 100% 具备 `rel="nofollow sponsored noopener"`

## 🛠️ 技术架构与特性 (Tech Stack & Features)

- **核心引擎**：[Hugo Extended](https://gohugo.io/)（纯静态站点生成，构建 95 个正式页面耗时仅 **300-600ms**）
- **UI 设计美学**：Dark Network Observatory（Grafana / Cloudflare Dashboard 极客暗黑终端风格）
  - 纯 CSS 原生变量设计，零臃肿前端框架依赖
  - 深度适配移动端与桌面端自适应排版，表格横向无溢出
  - 导航栏采用 `white-space: nowrap !important;` 保证单行优雅呈现
- **前沿 SEO / GEO 架构**：
  - **Answer-First 结构**：首屏标准 `GEO Answer Block`，天然契合 AI 搜索引擎（Perplexity、ChatGPT Search、Google AI Overviews）
  - **结构化数据 (JSON-LD)**：完备支持 `WebSite`、`Organization`、`BreadcrumbList`、`Article`、`FAQPage`
  - **规范化矩阵**：100% 绝对路径 Canonical 自引用，杜绝权重分散
  - **合规隔离**：全局 Goldmark 钩子，所有外部商业外链自动挂载 `rel="nofollow sponsored noopener"`
  - **全搜索引擎放行**：`robots.txt` 兼容 Googlebot、bingbot、Baiduspider、yisouspider（神马/夸克）
- **客户端交互**：
  - 本地 Fuse.js 全文极速搜索（快捷键 `Ctrl + K` 唤起）
  - 优惠码一键复制反馈
  - 动态多维度品牌筛选器（实测数据、IPLC专线、高性价比、AI优化）

## 🚀 本地开发与构建部署 (Getting Started)

### 1. 环境准备 (Prerequisites)
- [Hugo Extended](https://gohugo.io/installation/) (v0.120.0 或更高版本)
- [Node.js](https://nodejs.org/) (v18+，用于运行评测与审计脚本)
- [Git](https://git-scm.com/)

### 2. 本地调试与实时预览
克隆仓库后，在项目根目录启动 Hugo 本地开发服务器：

```bash
# 启动热重载开发服务器
hugo server -D

# 浏览器访问：http://localhost:1313/
```

### 3. 生产环境静态编译
执行正式构建，生成高密度生产静态网页：

```bash
# 清理旧目标并生成生产静态文件至 public/
hugo --cleanDestinationDir

# 输出验证：
# - 纯静态页面数：80-95 Pages
# - 编译速度：约 300-600ms
# - 生成站点地图：public/sitemap.xml
# - 生成爬虫协议：public/robots.txt
```

### 4. 生产部署建议 (Deployment)
- **Apache 环境**：根目录内置包含完整的 `.htaccess`，已配置 HTTPS 301 强制跳转、`www` 301 重定向至裸域、Gzip 压缩与静态资源长效缓存。
- **Cloudflare Pages / Vercel**：
  - Build Command: `hugo --gc --minify`
  - Output Directory: `public`
  - Hugo Version: `0.164.0`
